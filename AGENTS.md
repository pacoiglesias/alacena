# ALACENA: instrucciones del propietario

- Para cambios de la aplicación, completar la implementación, revisión, pruebas y compilación; actualizar GitHub y publicar la versión aprobada en Firebase. Comprobar la versión del sitio público antes de dar la entrega por terminada.
- Producción: `https://alacena.cobertores.com`; Firebase: proyecto y sitio `alacena-enterprise-prod`, target `alacena-app`. `alacena.bolsas.com` no está configurado.
- No publicar una compilación fallida ni presentar como publicado un despliegue no confirmado. Informar los bloqueos concretos.
- Mantener separadas las casas y unidades. No inventar nombres ni precios para códigos desconocidos. Las cantidades de productos pesados requieren tres decimales.
- Probar entradas, consumos, compras, tickets y devoluciones. No usar datos del hogar como datos de prueba ni registrar pruebas en producción.
- No incluir tokens, contraseñas ni claves de servicio en commits o registros.
